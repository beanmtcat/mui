# MUI Agent 0.6.24

Nodes can now drop connections to chosen domains. The list is set per node and
also applies to traffic that reaches the node through a route. sing-box matches
each entry with its subdomains, using the domain requested by the client or
sniffed from TLS SNI or an HTTP Host header. Nodes without a list keep an
identical configuration, so upgrading the Agent does not restart sing-box.

Changing a list restarts sing-box and drops that server's connections for a few
seconds. Sniffing delays server-first protocols on nodes with a list by up to
about 300 ms. Traffic with no visible domain cannot be matched.

The panel keeps apply jobs from an older Agent while an enabled node on that
server has a list, because that Agent would ignore it.
