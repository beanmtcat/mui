# MUI Agent 0.6.22

Agent stops and disables the managed sing-box service when no enabled nodes remain, while keeping the forwarder running. Re-enabling a node starts sing-box again. The installed core binary remains available for later use.

The panel queues a configuration apply when server roles change. For servers whose roles were changed under an older panel, the first Agent 0.6.22 report queues an apply to stop an idle sing-box service.

The amd64 and arm64 archives, standalone manifests, and signatures are built from this tagged commit. The panel serves installation scripts; target servers download the signed archives from GitHub Release.
