# MUI Agent 0.6.21

This release is built from the tagged source commit. The panel serves the online installer script; target servers download the signed amd64 or arm64 archive from this GitHub Release. Standalone copies of each architecture's signed `SHA256SUMS` and `SHA256SUMS.sig` were added for panel hash checks; they match the files inside the original archives. The panel waits at most 20 seconds per request while a shared background fetch can continue for up to five minutes and cache the verified hashes.

Agent 0.6.21 stops panel and Komari communication after the panel revokes its credential. The panel also offers an uninstall command for systemd and OpenRC hosts.

**Do not use v0.6.18, v0.6.19 or v0.6.20 for new online installs.** Their tags point to source that predates GitHub Release distribution, while their published binaries were built from later uncommitted code. Those releases are obsolete and their tags are left unchanged.
