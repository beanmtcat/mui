# MUI Agent 0.6.30

Port forwarding:

- A forwarded TCP connection that has never carried a byte in either
  direction is now closed after two minutes instead of one hour. A rule
  admits up to 4096 connections and up to 2048 from one source, so a few
  addresses opening connections and leaving them silent could hold a forward
  port's slots for an hour.
- Connections that have carried data keep the one-hour idle timeout, and the
  per-source and per-rule limits are unchanged, so traffic arriving from a
  single entry server through a route is not affected.

The core build is unchanged from 0.6.29: sing-box v1.14.4 with the ShadowTLS
v3 record framing patch.
