# MUI Agent 0.6.25

The routes page now measures hops that reuse a manual TCP + UDP forward. Agents
before this version skip those forwards, so the hop stays pending even though
traffic passes normally. Upgrade the server that owns
the manual forward; the servers on the rest of the route need no change.

Probes remain limited to forwards that belong to a route. A manual forward that
no route uses is not probed.
