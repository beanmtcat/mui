# MUI Agent 0.6.31

Host monitoring:

- `mui-agent` now reports host metrics (CPU, load averages, memory, swap, disk,
  network throughput and totals, TCP/UDP connection counts, process count,
  uptime, and static host hardware/OS details) directly to the MUI panel via
  signed `POST /agent/monitor` requests on an independent 5-second loop with
  30-second failure backoff.
- Assigned TCP ping latency tasks from the panel are executed on their
  configured schedule against validated public global-unicast literal IPs only,
  with results returned on subsequent monitor reports.
- External Komari JSON-RPC reporting has been removed in favor of the built-in
  MUI monitor backend.

The core build is unchanged from 0.6.29: sing-box v1.14.4 with the ShadowTLS
v3 record framing patch.
