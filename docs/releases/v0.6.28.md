# MUI Agent 0.6.28

Firewall fix:

- A manual UFW allow limited to loopback or private sources, such as
  `Anywhere ALLOW IN 172.18.0.0/16` for a Docker bridge network, no longer
  blocks firewall applies with "未经面板管理，却放行了全部端口". The check
  now reads the rule's source: traffic from 127/8, 10/8, 172.16/12,
  192.168/16, 169.254/16, ::1, fc00::/7 or fe80::/10 cannot arrive from the
  public internet, so such a rule bypasses no panel deny or restricted-source
  rule. A prefix wider than its private range (for example `10.0.0.0/7`) still
  counts as public, and manual allows from `Anywhere` or public addresses are
  refused as before.
