# MUI Agent 0.6.26

A node can now send its traffic out through a seller's SOCKS5 proxy. Clients
connect to your node with its own protocol, for example Shadowsocks, and the
sites they visit see the SOCKS5 proxy's address.

Add the seller's SOCKS5 as a node on an external server, then set the node's
egress to "经外部 SOCKS5 节点" and choose it. Only the server running the node
needs this Agent. Older Agents would ignore the setting and use the server's
own address, so the panel holds configuration back from them until they
upgrade.

UDP works only if the seller's SOCKS5 supports UDP ASSOCIATE. Changing the
node's egress restarts sing-box on that server.
